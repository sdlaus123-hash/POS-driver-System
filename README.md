# POMS ドライバー運用管理システム

GitHub / Vercel / GAS / Googleスプレッドシートで運用する、軽貨物ドライバー向けの管理システムです。

## ファイル構成

- `attendance.html`: 勤務報告
- `advance.html`: 前払い申請
- `holiday.html`: 休み希望
- `admin.html`: 管理画面
- `styles.css`: 共通デザイン
- `app.js`: 画面操作、ローカル保存、GAS連携
- `config.js`: GAS URL、固定URL、LINE設定
- `apps_script.gs`: GASバックエンド

## 使い方

1. GitHubにこのフォルダをアップロードします。
2. VercelでGitHubリポジトリを接続します。
3. Googleスプレッドシートを作成します。
4. GASに `apps_script.gs` を貼り付けます。
5. `SPREADSHEET_ID` をスプレッドシートIDに差し替えます。
6. GASをWebアプリとしてデプロイします。
7. `config.js` の `API_BASE_URL` にGAS Web App URLを入れます。

`API_BASE_URL` が空の間は、ブラウザの `localStorage` でデモ保存されます。

初回表示時には、動きが分かるようにデモのドライバー、現場、勤怠、前払い申請、口座情報、休み希望、管理者ログイン履歴が自動で入ります。管理画面の「デモ更新」を押すと、サンプル状態をもう一度作り直せます。

## 管理者ログイン

管理画面は毎回ログインが必要です。デモ時は `config.js` の `ADMIN_AUTH.demoPassword` を使います。

GAS連携後の本番ログインは、スプレッドシートの `AdminUsers` シートで判定します。管理画面の月別データ取得、ドライバー編集、現場編集、勤務修正、確定シフト保存などは、ログイン後の管理者トークンが必要です。

- 名前: `admin`
- デモ用4桁PIN: `1234`

本番利用前に必ず `AdminUsers` シートの4桁PINを変更してください。`AdminUsers` が空の場合は初期管理者として `admin / 1234` が作成されます。

ログイン履歴はローカルでは `localStorage`、GAS連携後は `AdminLogins` シートにも保存されます。

## ドライバーログイン

ドライバー画面は、GAS連携後に名前と4桁PINでログインします。PINは `Drivers` シートの `pin` 列、または管理画面のドライバー編集から変更できます。一度ログインした端末では、`DriverSessions` シートに保存したトークンを使ってログイン状態を維持します。

- ドライバー名: `Drivers.name`
- 4桁PIN: `Drivers.pin`

初期デモドライバーは `石塚 歩汰 / 1234` です。実運用では各ドライバーごとに別の4桁PINを設定してください。

ドライバーへLINE通知を送るには、`Drivers.lineUserId` にそのドライバーのLINE userIdを入れてください。

## 管理者LINE通知

出勤、退勤、前払い申請がGASに保存されたタイミングで、管理者用LINEへ通知できます。

`apps_script.gs` の先頭を設定してください。

```js
const LINE_CHANNEL_ACCESS_TOKEN = "LINE公式アカウントのチャネルアクセストークン";
const LINE_ADMIN_TO = "管理者のLINE userId または groupId";
```

通知される内容:

- 管理者への出勤通知: 誰が出勤したか、現場、勤務日、出勤時刻、区分、メモ
- 管理者への退勤通知: 誰が退勤したか、現場、勤務日、退勤時刻、区分、メモ
- 全員退勤サマリー: 出勤中の全員が退勤した時点で、本日の出勤人数と現場ごとの出勤メンバー
- 前払い通知: 指定の前払い申込文形式。ドライバー名、前払い金額、希望額、手数料、売上金額、対象期間、口座情報、振込名義人
- ドライバーへの朝8時通知: 休み希望日と通知停止日を除き、出勤確認URLを送信
- ドライバーへの夜23時通知: 休み希望日と通知停止日を除き、退勤確認URLまたは退勤完了確認を送信
- ドライバーへの前払い確認: 前払い申請が提出されたことを本人へ送信

`LINE_CHANNEL_ACCESS_TOKEN` と `LINE_ADMIN_TO` が未設定の場合、保存だけ行いLINE通知はスキップされます。

朝8時と夜23時のドライバー通知を使う場合は、GASで `setupPomsLineTriggers` を1回実行してください。これにより、`sendMorningDriverAttendanceNotices` と `sendNightDriverCheckoutNotices` の毎日実行トリガーが作成されます。

前払い通知の売上金額は、管理画面で設定したドライバー単価 × 稼働日数で計算します。管理画面のドライバー編集から、名前、現場、契約種別、単価、口座情報を変更できます。

前払い申請画面では、ドライバーが対象期間を選択すると、その期間内の出勤報告から実働日数を自動計算します。計算式は以下です。

- 売上金額 = ドライバー単価 × 実働日数
- 前払い希望額 = 売上金額 × 50%
- 前払い手数料 = 前払い希望額 × 8% + 260
- 前払い金額 = 前払い希望額 - 前払い手数料

管理画面のドライバー新規登録でも、銀行、支店、口座番号、名義を登録できます。

ドライバーが前払い申請で入力する項目は、対象開始日と対象終了日のみです。実働日数、希望額、手数料、前払い金額は自動計算されます。

同じドライバーが、過去の申請済み期間と重なる期間を申請することはできません。前払い画面には申請済み期間が表示され、重複する場合は申請ボタンが無効になります。GAS側でも保存前に重複チェックします。

前払い画面には振込予定金額を大きく表示し、今日、3日、7日、10日、15日のワンタップ期間選択と、実働日数・売上・手数料の見える化メーターを表示します。

前払い画面にはカレンダー型の期間選択もあります。出勤済み、申請済み、選択中の日を色分けし、開始日と終了日をタップで選択できます。

管理画面のドライバー管理では、選択中の月について以下を確認できます。

- ドライバーごとの出勤履歴
- 実働日数
- 単価
- その月の売上合計

GAS連携後は、管理画面ログイン時、月切替時、最新化ボタン押下時にスプレッドシートの月別シートから勤怠データを取得して表示します。

管理画面のダッシュボードでは、今月売上、前払い率、振込予定額、売上ランキング、優先アラートを確認できます。前払い管理では申請単位の詳細を開き、期間、実働日数、希望額、手数料、振込予定、口座情報を確認できます。

管理画面のメニューは、ダッシュボード、退勤管理、前払い、売上、管理の5つです。

- ダッシュボード: 本日稼働中、今月売上、売上ランキング、各ドライバー前払い金額概要
- 退勤管理: 今日の退勤状況、現場ごとの稼働人数、ドライバー別の出勤日数・代走日数・休み数、未退勤一覧
- 前払い: ドライバー別前払い回数・前払い希望合計・振込予定合計、申請一覧、口座情報、重複チェック履歴
- 売上: 現場別売上・人数、保存済み月、元請け入金明細の照合表、前払い履歴
- 管理: ドライバー管理、現場管理、休み希望、確定シフト、勤務修正、管理者ログイン履歴

変更を伴う操作はすべて管理メニューに集約しています。ドライバー追加・編集、現場追加・編集、ドライバー停止、現場停止、通常退勤修正、代走退勤処理、休み希望の全員分入力、確定シフトの全員分入力は管理メニューから行います。その他のメニューは詳細確認専用です。

管理画面上部の検索欄では、表示中メニュー内のドライバー名、現場名、金額などを絞り込めます。ダッシュボードには確認が必要な項目、管理メニューには口座情報、単価、現場紐付け、未退勤、休み希望、確定シフトの管理チェックを表示します。

売上メニューの「元請け入金明細 照合表」では、元請け明細に合わせて、ドライバー、現場、出勤日数、代走日数、単価、想定売上、休み、前払い回数を横並びで確認できます。

ドライバー別月次、現場別月次、前払い回数・合計、前払い申請一覧、口座情報、現場管理は表形式で表示します。PCでは横並びで素早く比較でき、スマートフォンでは1件ずつ読みやすいカード表示に切り替わります。

売上メニューには保存済み月へのジャンプを表示します。まだ読み込んでいない過去月は、上部の月選択で指定して最新化すると、GAS連携後は該当月のスプレッドシートから取得できます。

CSV書き出しには、勤怠、前払い、ドライバー別月次、現場別月次の集計行を含めます。分析用に、通常出勤日数、代走日数、休み希望数、単価、売上金額、前払い希望額、手数料、振込予定額を出力します。

勤怠データには `workType` を保存します。通常勤務は `normal`、代走は `substitute` として扱い、古いデータでもメモに「代走」が含まれる場合は代走として集計します。

現場を増やす場合は、管理メニューの「現場管理」から追加します。GAS連携後は `Sites` シートにも保存され、現場名を変更した場合は同じ現場IDを持つドライバーの現場名も更新されます。

過去データは管理画面上部の月選択から確認できます。GAS連携後は、スプレッドシート上にも `Attendance_YYYY_MM`、`Advance_YYYY_MM`、`Holiday_YYYY_MM`、`FixedShift_YYYY_MM` の月別シートとして残るため、分析に使えます。

## 固定URL

- 勤務報告: `https://pos-driver-system.vercel.app/attendance.html`
- 前払い申請: `https://pos-driver-system.vercel.app/advance.html`
- 休み希望: `https://pos-driver-system.vercel.app/holiday.html`
- 管理者用: `https://pos-driver-system.vercel.app/admin.html`

## 重要ルール

- 勤務日は0:00ではなく3:00切替です。
- 休み希望は毎月13日まで翌月分、14日以降は翌々月分です。
- LINE通知停止は休み希望ではなく `FixedShift_YYYY_MM` を基準にします。
- `Drivers` は固定マスタ、運用データは月別シートへ保存します。
